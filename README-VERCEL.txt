VERCEL UPLOAD INSTRUCTIONS

1. Extract this ZIP file.
2. Upload the CONTENTS of the syed-bilal-faheem-portfolio-vercel folder to the root of your GitHub repository.
3. Confirm that index.html and vercel.json are visible at the top level of the repository.
4. In Vercel, import that repository.
5. Select "Other" as the Framework Preset.
6. Leave Build Command empty.
7. Leave Output Directory empty (or enter a single period: .).
8. Deploy.

This package is the static public portfolio and includes Home, Portfolio,
Services, Awards, Contact, project images, and the Karachi-to-Kashmir project.

IMPORTANT ADMIN NOTE
The password-protected Admin Panel and permanent CMS saving use the database
provided by the current ChatGPT-hosted version. A plain static Vercel upload
cannot run that database-backed Admin Panel. Continue using the current hosted
site for Admin Panel editing, or connect a Vercel-compatible database before
moving the Admin Panel to Vercel.
